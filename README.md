# Calculator+ : Unified Smart Calculation System

Calculator+ is a multi-functional desktop calculator application developed using Python and Tkinter.  
It integrates Basic, Scientific, and Programmer calculators into a single platform, providing an efficient and user-friendly experience.

---

##  Features

- Multi-mode calculator (Basic, Scientific, Programmer)
- Clean and interactive user interface
- Advanced scientific operations
- Programmer tools with base conversions and bitwise operations
- Calculation history with timestamp (last 24 hours)
- ASCII conversion functionality
- Fibonacci series generator with popup display

---

##  Modules Overview

### 🔹 1. Basic Calculator
The Basic Calculator is designed for everyday calculations.

**Features:**
- Addition, subtraction, multiplication, and division
- Percentage calculations
- Clear and backspace functionality
- Simple and user-friendly interface

👉 This module provides fast and accurate results for basic arithmetic operations.

---

### 🔹 2. Scientific Calculator
The Scientific Calculator supports advanced mathematical operations.

**Features:**
- Trigonometric functions (sin, cos, tan)
- Logarithmic and exponential functions
- Square root and power operations
- Mathematical constants (π, e)

👉 This module is useful for solving complex mathematical problems efficiently.

---

### 🔹 3. Programmer Calculator
The Programmer Calculator is designed for developers and advanced users.

**Features:**
- Number system conversions:
  - Binary, Octal, Decimal, Hexadecimal
- Bitwise operations:
  - AND, OR, XOR, NOT, Left Shift, Right Shift
- Low-level computation support

👉 This module helps in understanding binary operations and debugging tasks.

---

##  Output Features

### 🔸 Fibonacci Series Output
- User enters a number (n)
- A popup window opens displaying:
  - Fibonacci sequence up to n terms
  - The nth Fibonacci value

👉 This feature provides a clear and formatted output in a separate window.

---

### 🔸 ASCII Conversion Output
- User can input a number or text
- The system performs:
  - Number → Character conversion
  - Text → ASCII values conversion
- Output is displayed in a popup window

👉 This allows easy conversion between characters and ASCII codes.

---

## 🕒 History Feature

- Stores recent calculations automatically
- Displays date and time for each calculation
- Maintains history for the last 24 hours
- Helps users review previous results easily

---

## 🛠️ Technologies Used

- **Python** – Core programming language  
- **Tkinter** – GUI framework  
- **Math Module** – Scientific calculations  
- **Datetime Module** – History tracking
